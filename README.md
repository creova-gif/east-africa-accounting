# East Africa Accounting Platform

**A QuickBooks-level accounting platform built specifically for East Africa (Kenya, Tanzania, Uganda, Rwanda, Burundi).**

## Overview
A double-entry accounting platform purpose-built for East African tax regimes and mobile-money-first business realities, not an adapted Western product.

## Problem
Generic accounting software (QuickBooks, Xero) isn't built for East African VAT rules, e-invoicing mandates (TIMS, EFRIS, VFD, EBM), or mobile money reconciliation, and often assumes reliable internet access.

## Solution
Country-specific VAT rates and e-invoicing compliance built in from the start, mobile money integration (M-Pesa, Airtel, Tigo, MTN), offline-first design, and simple language for non-accountant users.

## Key Capabilities
- Double-entry bookkeeping, transaction management, invoicing with auto-VAT
- Financial reports: P&L, Balance Sheet, Cash Flow, VAT Summary
- Multi-currency: KES, TZS, UGX, RWF, BIF
- Country compliance: Kenya (TIMS/KRA), Tanzania (VFD/TRA), Uganda (EFRIS/URA), Rwanda (EBM/RRA), Burundi
- AI expense categorization, tax filing reminders, offline support

## Getting Started

```bash
cd east-africa-accounting
npm install
npm run dev
```
